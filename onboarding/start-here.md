# Start Here — Reading Path

New to this repo? Read in this order. Each document builds on the last. Total time: about 45 minutes.

## 1. How this repo works (10 min)

- **`README.md`** — the SOP lifecycle, the maturity model, the principles. Read this first or nothing else makes sense.

## 2. Who owns what (5 min)

- **`ownership/raci.md`** — who is responsible and accountable for each process. When something breaks, this is where you look.

## 3. When things go wrong (10 min)

- **`incident-response/severity-definitions.md`** — the shared language for how bad it is.
- **`incident-response/escalation-matrix.md`** — who gets involved, in what order.

## 4. The daily work (15 min)

- **`onboarding/access-matrix.md`** — what each role gets. The reference for all provisioning.
- **`onboarding/new-hire-checklist.md`** — bringing someone on.
- **`onboarding/offboarding-checklist.md`** — seeing someone off. Read the time targets.

## 5. The bigger picture (5 min)

- **`ownership/toil-register.md`** — where the repetitive work lives and what's being automated.
- **`compliance/control-mapping.md`** — how the procedures satisfy PCI and GLBA.

## After that

Everything else is reference. Read the procedure you need when you need it. If you're writing a new SOP, start with `templates/sop-template.md`.

## For managers

If you're approving access or reviewing compliance, you need: `ownership/raci.md`, `onboarding/access-matrix.md`, and `compliance/control-mapping.md`. That's the 15-minute version.
